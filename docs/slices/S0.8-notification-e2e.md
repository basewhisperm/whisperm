# Slice S0.8 Notification End-to-End Integration

## Goal

Wire existing notification infrastructure into the tenant lifecycle.

## Existing Components

- tenant.created event
- NotificationService
- Resend provider
- Notification runtime
- Scheduler runtime
- Worker runtime

## Required Wiring

### A. Tenant Created Consumer

Consumes:

tenant.created

Actions:

1. Resolve tenant owner/admin user.
2. Send welcome email.
3. Schedule trial reminders.

### B. Trial Reminder Scheduling

Create jobs:

- D-3
- D-1
- D+0

using scheduler-runtime.

### C. Worker Registration

Register:

notification.trial_reminder

Worker executes:

executeTrialReminderJob()

### D. Acceptance Criteria

- tenant.created sends welcome email.
- tenant.created schedules 3 jobs.
- duplicate tenant.created remains idempotent.
- notification.trial_reminder executes successfully.
- pnpm -r build passes.
- pnpm -r test passes.
